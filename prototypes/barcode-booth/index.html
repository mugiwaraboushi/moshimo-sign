バーコード → 電光掲示板

バーコードリーダーで読んだ文字を、USBでつないだ掲示板に送ります。会場にWiFiが無くても動きます。
Chrome か Edge で開いてください（パソコンのみ。Safari・スマホは使えません）。
まだつないでいません
「掲示板につなぐ」を押して、出てきた一覧から掲示板（USB Serial / CH340 など）を選んでください。 つないだ瞬間に掲示板が一度再起動することがあります（数秒で戻ります）。
この欄にカーソルがある状態でバーコードを読むと、文字とEnterが入って自動で送られます。 手で打って Enter でも送れます。カーソルが外れていたら、欄をクリックしてください。
掲示板側の設定: playlist.json の sayEnabled:true（入力を受け付ける）、sayReplace:true（後から読んだものを優先）、 sayFrames（もしもくんの枠）、sayTextW、sayHoldMs:5000。ファームウェア v23 以降。
送っているのは USB シリアルの1行 say 文字（115200bps）。 ／ プロトタイプ一覧
