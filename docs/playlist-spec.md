# playlist.json 仕様 (v1)

実機(ESP32)はGitHub Pages上の `playlist.json` を約60秒ごとに取得し、表示内容を更新する。
**このファイルをpushするだけで、もしもに設置された実機の表示が変わる。**
メンバーの「実機テスト」はこのファイルの更新で行う(ファームウェア自体の変更はファームウェア担当のみ)。

## フィールド

| キー | 型 | 意味 | 例 |
|---|---|---|---|
| `topText` | string | 上段の固定文言 (時計と交互表示) | `"営業中"` |
| `mode` | string | `"dual"`=2段 / `"scroll"`=1行スクロール / `"frames"`=ドット絵 | `"dual"` |
| `brightness` | int | 輝度 8-255 | `96` |
| `speed` | number | スクロール速度 dot/秒 (5-200) | `45` |
| `colorTop` | string | 上段の色 (RGB 16進6桁、#なし) | `"FF9C00"` |
| `colorScroll` | string | 下段スクロールの色。RGB 16進6桁、または特殊値 `"rainbow"` | `"FF9C00"` / `"rainbow"` |
| `messages` | string[] | スクロールで流す文言 (最大10件、◆で連結される) | |
| `frames` | object[] | ドット絵の静止画 (最大8枚)。`mode:"frames"` のときだけ使われる | |

- 省略したキーは現在値を維持する
- イベント時のコメント(COMMENTS_URL経由)は `messages` の後ろに自動で連結される
- 上段は全角3〜4文字が収まる (64dot幅 ÷ 16dot/文字)
- 反映まで最大1〜2分 (取得間隔60秒 + CDNキャッシュ)

### レインボースクロール (v0.4〜)

`colorScroll` に `"rainbow"` を指定すると、下段のスクロールが虹色になる。

```json
{ "colorScroll": "rainbow" }
```

- **1文字ごとに色相が24°ずつ進む** ため、文字列に沿って虹のグラデーションがかかる
- 基準色相は時間で回転し、**約7.2秒で一周**する。文字は止まって見えても色は流れ続ける
- **対象は下段スクロールのみ。** 上段 (`colorTop`) は対象外で、指定した色のまま
- 周期・回転速度は固定 (v0.4ではパラメータ化していない)。細かく詰めたい場合は
  ビューア [`prototypes/rainbow/`](../prototypes/rainbow/) で試せる
- `"rainbow"` 以外の文字列は従来通りRGB 16進6桁として解釈される。
  16進として不正な値の場合は黒 (`0x0000`) になり、下段が消灯するので注意

> 設計メモ: 当初案は `colorMode` + `rainbowCycle` / `rainbowSpin` という新規フィールドだったが、
> 仕様の追加面積を最小にするため既存 `colorScroll` の特殊値として実装した。

### ドット絵 frames (v0.5〜 / playlist v2.0)

お絵かきツール [`prototypes/draw/`](../prototypes/draw/) で描いた絵を、そのまま実機に出せる。
**v2.0は静止画のみ**(パラパラ動かすアニメーションは未対応)。

```json
{
  "mode": "frames",
  "frames": [
    { "d": "AAAAAcAAAAA…(342文字)", "color": "FF9C00", "hold": 8 }
  ]
}
```

| キー | 型 | 意味 | 既定 |
|---|---|---|---|
| `frames[].d` | string | 64×32のドット絵。base64url **342文字固定** | 必須 |
| `frames[].color` | string | 発光色。RGB 16進6桁 (`colorTop` と同じ形式) | `colorTop` の値 |
| `frames[].hold` | number | 表示秒数 (1〜60) | `8` |

#### 描いた絵を載せる手順

1. `prototypes/draw/` で絵を描く (**パネル構成は「64×32（1枚）」を選ぶ**)
2. 「playlist用をコピー」ボタンを押す → `{ "d": "…", "color": "…" }` がそのままコピーされる
3. それを `frames` の配列に貼り、`mode` を `"frames"` にして commit + push

URLから手で切り出す場合は、`#s=1&c=0&d=XXXX` の **`d=` 以降がそのまま `"d"` の値**になる。
`c=` は色番号なので、`color` には下の表の16進を書く:

| `c=` | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| `color` | `FF9C00` | `FF3B30` | `2EFF5E` | `27E0FF` | `FFFFFF` | `3B7BFF` |

#### 仕様の細部

- **データ形式**: 1ドット1bitのモノクロ。左上から行優先、1バイト＝8ドット、**MSBが左**。
  64×32 = 2048bit = 256バイト → base64url (パディング無し) で342文字
- **サイズは64×32固定**。draw の「64×16」「128×32」「192×32」(`s=0/2/3`) は v2.0では非対応
- `frames` が2枚以上あると、`hold` 秒ごとに次の絵へ切り替わり、最後まで行くと先頭に戻る
- `mode:"frames"` のときは**上段テキストも下段スクロールも出ない**(画がパネル全面)
- `mode` が `"dual"` / `"scroll"` のときは `frames` があっても無視される
- `d` の長さが342でない・base64として不正なフレームは**そのフレームだけ捨てて**残りを表示する
  (`messages` と違い、1枚壊れても画面が消えない)
- `mode:"frames"` なのに有効なフレームが0枚のときは `"dual"` にフォールバックする(黒画面にしない)
- 色はフレーム単位。1枚の絵の中で色を塗り分けることはできない(パネル全体の発光色として効く)
- `colorScroll` の `"rainbow"` は `frames` では使えない(v2.0では16進6桁のみ)

## 更新時の注意 (Claude向け・人間向け共通)

1. 変更前にJSONとして妥当か確認する (壊れたJSONは実機側で無視される=表示は前のまま)
2. 公共の場に出る文言なので、もしもの場に相応しい内容か確認する
3. 誰の依頼でいつ変えたかをコミットメッセージに残す。ただし**実名は書かない** — Discordの表示名かイニシャルを使う
   (例: `playlist: イベント告知を追加 (@discord表示名 の依頼)` / `playlist: 文言を修正 (M.S. の依頼)`)
   - このリポジトリは公開されるため、コミットログも誰でも読める。実名と発言の結びつきを残さない
   - 表示名と実名の対応が必要な場合は、git管理外の `CLAUDE.local.md` に控える

## 将来の拡張

- `frames` のアニメーション化: `hold` の最小値を秒未満に下げ、コマ送りで動かす
  (データ形式は静止画版のまま変えずに済む想定)
- `frames` の 128×32 / 192×32 対応 (パネルを増設したとき)
- `frames[].color` の `"rainbow"` 対応。静止画に対する虹の当て方 (横方向のグラデか、時間で回すか) を
  決める必要があるため v2.0では見送り
- `schedule`: 時間帯による表示切替 (営業中/閉店)
