# 大岡山 発車標のデータ形式

`prototypes/train-board/` は、`data/timetable-ookayama.json` があればそれを読んで表示し、
無ければ**サンプルのダミー時刻表**で動く。実データを置けば、ページ側の変更なしで本物になる。

## ファイルの形

```json
{
  "updated": "2026-08-11",
  "station": "大岡山",
  "source": "どこから持ってきたかを必ず書く（ODPT / 駅の時刻表 など）",
  "lines": [
    {
      "name": "目黒線",
      "dirs": [
        { "to": "目黒", "trains": [ { "t": "05:07", "type": "各停" }, { "t": "05:14", "type": "急行" } ] },
        { "to": "日吉", "trains": [ { "t": "05:11", "type": "各停" } ] }
      ]
    },
    {
      "name": "大井町線",
      "dirs": [
        { "to": "大井町", "trains": [ { "t": "05:02", "type": "各停" } ] },
        { "to": "溝の口", "trains": [ { "t": "05:09", "type": "各停" } ] }
      ]
    }
  ]
}
```

- `lines` の順番がそのまま画面の段になる。**1本目が上段（目黒線）、2本目が下段（大井町線）**。
- `t` は `"HH:MM"`。24時以降の列車は `"24:05"` のように書いてよい。
- `type` は書いた文字がそのまま出る（各停 / 急行 など）。
- `trains` は**時刻の昇順**で並べる。先頭から見て最初の未発車を「次発」とする。
- 平日・土休日の出し分けは**まだ未対応**。分けるならファイルに `weekday` / `holiday` を足して、
  ページ側の読み込みも直す必要がある。

## 実データの入れ方

### 1. 公共交通オープンデータセンター（ODPT）から取る
東急の駅時刻表が配布されている。開発者登録（無料）でAPIキーをもらい、
ニュース表示（`prototypes/news/` と `.github/workflows/news.yml`）と同じ形で
GitHub Actions から1日1回取得して `data/timetable-ookayama.json` に書き出す。

- APIキーは**リポジトリに置かない**。GitHubのSecretsに入れてActionsから使う。
- 出典の表記が求められるので、`source` に書いてページにも出す。

### 2. 駅の時刻表を手で入れる
平日・土休日 × 4方面ぶん。写真を送ってもらえれば起こせる。
一度入れればダイヤ改正まで使えるので、まずはこちらでも十分動く。

## 実機に出すときの注意

いまのファームウェアは**上段が固定文言・下段がスクロール**なので、この2段スクロールはそのままでは出せない。
実機に出すには、次のどちらかが要る。

- ファームウェアに「2段とも独立してスクロールする」モードを足す
- 上段を「目黒線 09:09 各停 目黒」のように4文字以内に切り詰めて固定表示にする（情報量は落ちる）
